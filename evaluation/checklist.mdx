Work through these during the PoC. Each item links to where in this site you can verify it. Findings and evidence are written up in [Mintlify: pros and cons](/evaluation/mintlify-pros-cons).

## Authoring experience

- [x] MDX authoring feels good in our normal git + PR workflow — verified: Parse section built and iterated entirely as MDX in git
- [x] Local preview (`mint dev`) is fast and matches production — hot reload for content, `docs.json` and theme
- [x] `mint broken-links` catches dead links in CI — also catches MDX parse errors; workflow in `.github/workflows/docs-check.yml`
- [x] AI-assisted editing works with our agents (docs are plain MDX in a repo)

## Content capabilities

- [x] Built-in components cover our needs — see [Component showcase](/evaluation/component-showcase); no custom React needed for the Parse section
- [x] Multi-language code groups (Python / TS / Go / Java / CLI) — see [Quickstart](/quickstart)
- [x] Reusable snippets for shared scaffolding — 70 duplicated blocks on 10 pages replaced, see `/snippets`
- [x] Mermaid / diagrams render well — see [Retrieving results](/parse/guides/retrieving-results) and the [home page](/)
- [x] Changelog with tag filters and RSS — built-in `Update` component, see [Changelog](/changelog)
- [ ] LaTeX (if we ever need it for eval metrics)

## API reference

- [x] OpenAPI spec → generated pages with zero manual work — 27 pages from the real spec, see [API Reference](/api-reference/parse/parse-file)
- [x] Guides deep-link to generated endpoint pages — see [REST API guide](/parse/guides/api-reference)
- [ ] Interactive "try it" playground works against our real API
- [ ] Auth (bearer token) is configurable in the playground — declared in the spec; not yet exercised
- [ ] Spec updates flow through automatically on push — requires re-running the filter script

## Platform

- [ ] Custom domain (`docs.llamaindex.ai`) support
- [ ] Search quality on real content
- [ ] Built-in AI assistant answer quality
- [ ] Analytics: what pages people read, search terms with no results
- [x] Versioning — v1 (legacy) is behind the version dropdown
- [x] Redirects from old URLs — 40 generated in `docs.json` (exact-match only; no regex)
- [x] `llms.txt` / markdown export for AI crawlers — automatic on hosting; contextual "open in Claude / Cursor / MCP" menu enabled

- [x] Preserving URL structure or mapping redirects — redirect map generated by the converter
- [x] Handling auto-generated API docs — replaced by the published OpenAPI spec, filtered per product
