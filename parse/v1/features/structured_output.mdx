## About Structured Output

Structured output allows you to extract structured data (such as JSON) from a document directly at the parsing stage, reducing cost and time needed.

Structured output is currently only compatible with our default parsing mode and can be activated by setting `structured_output=True` in the API.

<Tabs>
  <Tab title="Python">
  ```python
  parser = LlamaParse(
    structured_output=True
  )
  ```
  </Tab>
  <Tab title="API">
  ```bash
  curl -X 'POST' \
    'https://api.cloud.llamaindex.ai/api/v1/parsing/upload'  \
    -H 'accept: application/json' \
    -H 'Content-Type: multipart/form-data' \
    -H "Authorization: Bearer $LLAMA_CLOUD_API_KEY" \
    --form 'structured_output="true"' \
    -F 'file=@/path/to/your/file.pdf;type=application/pdf'
  ```
  </Tab>
</Tabs>

<br />
<br />

You then need to provide either:

- a JSON schema in the `structured_output_json_schema` API variable, which will be used to extract data in the desired format
- or the name of one of our pre-defined schemas in the variable `structured_output_json_schema_name`

<Tabs>
  <Tab title="Python (Schema)">
  ```python
  parser = LlamaParse(
    structured_output_json_schema='A JSON SCHEMA'
  )
  ```
  </Tab>
  <Tab title="API (Schema)">
  ```bash
  curl -X 'POST' \
    'https://api.cloud.llamaindex.ai/api/v1/parsing/upload'  \
    -H 'accept: application/json' \

    -H "Authorization: Bearer $LLAMA_CLOUD_API_KEY" \
    --form 'structured_output_json_schema="A JSON SCHEMA"' \
    -F 'file=@/path/to/your/file.pdf;type=application/pdf'
  ```
  </Tab>
  <Tab title="Python (Preset)">
  ```python

    structured_output_json_schema_name="invoice"
  )
  ```
  </Tab>

## Invoice

Standard invoice schema for line items, tax, and totals

<Tabs>
  <Tab title="API">
  ```bash
    curl -X 'POST' \
      'https://api.cloud.llamaindex.ai/api/v1/parsing/upload'  \
      -H 'accept: application/json' \
      -H 'Content-Type: multipart/form-data' \
      -H "Authorization: Bearer $LLAMA_CLOUD_API_KEY" \
      --form 'structured_output_json_schema_name="invoice"' \
      -F 'file=@/path/to/your/file.pdf;type=application/pdf'
  ```
  </Tab>
  <Tab title="Invoice Schema">
  #### Structured Output: Invoice Schema

Type: `object`

**_Properties_**

 - <b id="#/properties/invoiceNumber">invoiceNumber</b> `required`
	 - _Unique identifier for the invoice_
	 - Type: `string`
 - <b id="#/properties/invoiceDate">invoiceDate</b> `required`
	 - _Date the invoice was issued (ISO format)_
	 - Type: `string`
	 - String format must be a "date"
 - <b id="#/properties/dueDate">dueDate</b>
	 - _Payment due date (ISO format)_
	 - Type: `string`
	 - String format must be a "date"
 - <b id="#/properties/billingAddress">billingAddress</b> `required`
	 - _Billing address details_
	 - Type: `object`
	 - **_Properties_**
		 - <b id="#/properties/billingAddress/properties/name">name</b> `required`
			 - Type: `string`
		 - <b id="#/properties/billingAddress/properties/street">street</b> `required`
			 - Type: `string`
		 - <b id="#/properties/billingAddress/properties/city">city</b> `required`
			 - Type: `string`
		 - <b id="#/properties/billingAddress/properties/state">state</b>
			 - Type: `string`
		 - <b id="#/properties/billingAddress/properties/postalCode">postalCode</b> `required`
			 - Type: `string`
		 - <b id="#/properties/billingAddress/properties/country">country</b> `required`
			 - Type: `string`
 - <b id="#/properties/shippingAddress">shippingAddress</b>
	 - _Shipping address details_
	 - Type: `object`
	 - **_Properties_**
		 - <b id="#/properties/shippingAddress/properties/name">name</b> `required`
			 - Type: `string`
		 - <b id="#/properties/shippingAddress/properties/street">street</b> `required`
			 - Type: `string`
		 - <b id="#/properties/shippingAddress/properties/city">city</b> `required`
			 - Type: `string`
		 - <b id="#/properties/shippingAddress/properties/state">state</b>
			 - Type: `string`
		 - <b id="#/properties/shippingAddress/properties/postalCode">postalCode</b> `required`
			 - Type: `string`
		 - <b id="#/properties/shippingAddress/properties/country">country</b> `required`
			 - Type: `string`
 - <b id="#/properties/items">items</b> `required`
	 - _List of items included in the invoice_
	 - Type: `array`
		 - **_Items_**
		 - Type: `object`
		 - **_Properties_**
			 - <b id="#/properties/items/items/properties/description">description</b> `required`
				 - _Description of the item_
				 - Type: `string`
			 - <b id="#/properties/items/items/properties/quantity">quantity</b> `required`
				 - _Quantity of the item_
				 - Type: `number`
				 - Range:  &ge; 1
			 - <b id="#/properties/items/items/properties/unitPrice">unitPrice</b> `required`
				 - _Price per unit of the item_
				 - Type: `number`
				 - Range:  &ge; 0
			 - <b id="#/properties/items/items/properties/totalPrice">totalPrice</b> `required`
				 - _Total price for this item_
				 - Type: `number`
				 - Range:  &ge; 0
 - <b id="#/properties/subTotal">subTotal</b> `required`
	 - _Subtotal for all items_
	 - Type: `number`
	 - Range:  &ge; 0
 - <b id="#/properties/tax">tax</b> `required`
	 - _Tax details_
	 - Type: `object`
	 - **_Properties_**
		 - <b id="#/properties/tax/properties/rate">rate</b> `required`
			 - _Tax rate as a percentage_
			 - Type: `number`
			 - Range:  &ge; 0
		 - <b id="#/properties/tax/properties/amount">amount</b> `required`
			 - _Total tax amount_
			 - Type: `number`
			 - Range:  &ge; 0
 - <b id="#/properties/total">total</b> `required`
	 - _Total amount due (subtotal + tax)_
	 - Type: `number`
	 - Range:  &ge; 0
 - <b id="#/properties/notes">notes</b>
	 - _Additional notes or instructions for the invoice_
	 - Type: `string`
 - <b id="#/properties/status">status</b> `required`
	 - _Current payment status of the invoice_
	 - Type: `string`
	 - The value is restricted to the following: 
		 1. _"Paid"_
		 2. _"Unpaid"_
		 3. _"Overdue"_

  </Tab>
</Tabs>

			 - _e.g. Web Developer_
			 - Type: `string`
		 - <b id="#/properties/basics/properties/image">image</b>
			 - _URL (as per RFC 3986) to a image in JPEG or PNG format_
			 - Type: `string`
		 - <b id="#/properties/basics/properties/email">email</b>
			 - _e.g. thomas@gmail.com_
			 - Type: `string`
			 - String format must be a "email"
		 - <b id="#/properties/basics/properties/phone">phone</b>
			 - _Phone numbers are stored as strings so use any format you like, e.g. 712-117-2923_
			 - Type: `string`
		 - <b id="#/properties/basics/properties/url">url</b>
			 - _URL (as per RFC 3986) to your website, e.g. personal homepage_
			 - Type: `string`
			 - String format must be a "uri"
		 - <b id="#/properties/basics/properties/summary">summary</b>

					 - Type: `string`
